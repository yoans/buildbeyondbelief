# Build Beyond Belief

Static site for [buildbeyondbelief.com](https://buildbeyondbelief.com).

No server. No database. Booking is a Cal.com embed. The project questionnaire opens an email draft.

## Pages

- `/` home
- `/book/` Project Assessment
- `/fit-call/` free fit call
- `/work/` case studies
- `/blueprint/` and `/ai-native-engineer-checklist/`
- `/project-questionnaire/`

GitHub Pages serves this repo. `buildbeyondbelief.com` is the custom domain in `CNAME`.
